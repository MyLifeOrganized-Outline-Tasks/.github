# MyLifeOrganized

> One named MyLifeOrganized outline. Finish the next action. Leave a note the next project can read.

## Session Card

| Slice | What you do in MyLifeOrganized | What remains |
|-------|------------------------|--------------|
| Outline | Open MyLifeOrganized and name today's life desk | A titled project tree |
| Next | Keep only live next actions on the MyLifeOrganized board | A short action list |
| Tree | Read MyLifeOrganized outline tasks before a large change | A confirmed hierarchy |
| Handoff | Mark finished actions inside MyLifeOrganized | A note for the next visit |

## How MyLifeOrganized Sits

MyLifeOrganized does not replace the paper outline, the kanban board, or the calendar you already keep. It sits beside them as a named life desk for one job: which outline tasks are live, which project tree still shows next actions, and what the next person should read before the next hierarchy pass.

## Traffic Light

| Signal | On the MyLifeOrganized board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live next-action list | Continue the same project tree |
| Amber | Two projects mixed in one outline | Split the tree before you mark next |
| Red | No title, no note, actions unlabeled | Stop and name the outline first |
| Clear | Handoff written, live actions few | Close MyLifeOrganized and leave the desk |

## Open Order

1. Open the last MyLifeOrganized life desk, not a new empty project tree.
2. Read the outline tasks and the last handoff.
3. Finish one visible next action inside MyLifeOrganized.
4. Write what changed, then close with fewer unlabeled actions than you found.
5. If the outline feels crowded, drop anything that belongs to a different MyLifeOrganized project.

## Desk Fit

| Who | What MyLifeOrganized holds |
|-----|--------------------|
| Life desk | Outline tasks, project tree, and the next actions you mark |
| Shared PC | One MyLifeOrganized profile per person |
| Support | A repeatable MyLifeOrganized layout for the same tree |
| Home projects | Personal outlines out of the work hierarchy |

## After a Week

A week in MyLifeOrganized is not a larger unlabeled action pile. It is the same title, a shorter live project tree, and a note that still makes sense before the next action. Take finished items off the live set so the next visit starts on the outline that is still open.

## Sign-off

- [ ] The MyLifeOrganized workspace name is short enough to scan
- [ ] Only live next actions sit on the tree
- [ ] A second person can read the outline handoff
- [ ] The last MyLifeOrganized life desk still opens after a restart

## Field Note

MyLifeOrganized is easier to trust when the life desk stays smaller than the project pile it came from. Name the outline, keep the live next actions, finish one visible step, and write what changed.
